# Capstone Project: Engineering Agent 工业仿真受控自动化系统

## 📌 项目定位
本项目是全课程第六季的毕业综合示范工程。
它演示如何利用现代大语言模型作为**自然语言意图理解器与参数翻译器**，但将**实际执行、物理边界校验与危险操作审批**严格交由确定性 Python 状态机与人类工程师把关。

---

## 🏛️ 系统架构 (Architecture)

```text
               ┌───────────────────────┐
               │  Human Engineer (UI)  │
               └──────────┬────────────┘
                          │ 1. 自然语言需求
                          ▼
               ┌───────────────────────┐
               │ LLM Agent (Planner)   │
               └──────────┬────────────┘
                          │ 2. 生成结构化任务契约 (JSON)
                          ▼
  ┌─────────────────────────────────────────────────────────┐
  │         Controlled State Machine (确定性控制器)          │
  │                                                         │
  │  [Schema 校验] ──> [物理参数合法性检查] ──> [安全阈值判断]   │
  │                                           │             │
  │        ┌──────────────────────────────────┘             │
  │        ▼                                                │
  │  [人工审批门禁 (Human Gate)] ──(通过)──> [执行本地求解脚本] │
  │                                           │             │
  │                                           ▼             │
  │                                  [日志分析与指标比对]     │
  └─────────────────────────────────────────────────────────┘
```

---

## 🛡️ 核心工程防御机制 (Defensive Features)

1. **强类型参数校验**：使用 Pydantic/dataclasses 强约束雷诺数、网格精度与迭代步数，绝不执行负数步长或非法网格。
2. **人工审批断点 (Human-in-the-loop Gate)**：任何涉及耗时超过 5 分钟或调用高性能计算集群的仿真计算，必须暂停状态机，弹出确认摘要待人类工程师签字确认。
3. **不可变审计追踪**：每次规划决策、代码修改与求解器指标均输出为结构化 JSON 日志，永久归档以供溯源。
