# 第一季：计算环境与开发工具 (Season 01)

> **01–05 · 工程师如何可靠地操作计算机**  
> 主力对齐教材：[MIT The Missing Semester of Your CS Education (2026)](https://missing.csail.mit.edu/2026/) · [Pro Git (2nd Edition)](https://git-scm.com/book/zh/v2)

---

## 🎯 季度核心目标
对于跨行业工程师而言，很多工程挫折并不是因为算法不懂，而是死在“环境配置错误、文件路径混乱、后台进程被意外中断、Git 提交被覆盖”等基础工程泥潭中。
本季的目标是建立**对操作系统、进程、I/O 数据流与版本控制的透明理解**，能够编写出健壮、可批处理、具备明确退出码的工业流式处理工具。

---

## 📚 单元规划与核心机制

### [01] Shell 与进程机制：命令究竟在哪里执行？
- **核心概念**：工作目录、`$PATH` 环境变量解析机制、Linux 进程生命周期、父子进程继承关系、进程退出码（Exit Code）。
- **避坑警示**：永远不要假设用户当前路径；严禁使用未声明的环境变量。
- **推荐阅读**：Missing Semester 2026 *Course Overview + The Shell*。

### [02] I/O 重定向与管道：数据流的组合艺术
- **核心概念**：标准输入 (0), 标准输出 (1), 标准错误 (2)；`>` 与 `>>` 重定向区别；管道 `|` 的单向字节流缓冲；`set -euo pipefail` 工业防御性配置。
- **避坑警示**：默认情况下管道中的中间失败会被最后一个命令掩盖，导致静默错误。

### [03] 数据流与文本处理：从凌乱日志到结构化数据
- **核心概念**：流式行处理模型；`grep` 正则过滤；`awk` 字段提取与条件运算；`jq` 处理 JSON 流；内存消耗对比（流式处理 vs 一次性加载）。
- **实战配套**：[Lab 01: 求解器日志解析流水线](../../../labs/01-shell-log-pipeline/README.md)。

### [04] SSH 与远程会话：长时间工程计算的守护神
- **核心概念**：非对称密钥认证（Ed25519）；SSH 隧道端口转发；Tmux 会话解耦；SIGHUP 信号与终端断开防护。
- **实战要求**：掌握在云服务器断开连接后，后台计算任务依然平稳运行的会话管理技巧。

### [05] Git 底层原理：配置与代码变更如何被精准追踪
- **核心概念**：Git 内容寻址文件系统（Blob, Tree, Commit, Tag）；工作区、暂存区、版本库三重境界；合并冲突的本质与安全变基（Rebase）。
- **推荐阅读**：Pro Git 简体中文版第 1-3 章与第 10 章“Git 内部原理”。
