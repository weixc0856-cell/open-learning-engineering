## 🎯 季度核心目标
撕下深度学习的神秘外衣：通过从零手写标量自动微分引擎（Micrograd），透彻理解计算图与反向传播的本质。
进而探索现代前沿——科学机器学习（Scientific ML）：物理信息神经网络（PINN）与傅里叶神经算子（FNO），讨论将偏微分方程（PDE）残差作为损失函数时的收敛挑战与工业适用边界。
