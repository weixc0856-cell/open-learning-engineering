# 第五季：深度学习与科学机器学习

> **第 21–25 单元｜从梯度到物理问题，理解模型如何学习、何时失效**

本季把深度学习当作可检验的数值方法来学习，而不是只关注模型结构和演示效果。重点是计算图、梯度、泛化、卷积、物理约束以及神经算子的适用边界。

<div class="season-meta" markdown>
**建议投入：** 4–6 周　 ·　 **先修：** 函数、向量/矩阵、导数与基础概率　 ·　 **最终产出：** 一个有基线、有数据划分、有误差分析的科学机器学习实验

## 学完后，你应该能做什么？

- 用链式法则解释反向传播，理解自动微分计算的是什么。
- 区分训练误差、验证误差与测试误差，识别过拟合和数据泄漏。
- 解释 CNN 的局部感受野、参数共享与张量形状变化。
- 写出简单 PINN 的方程残差、边界条件和损失项，并识别优化困难。
- 判断神经算子代理模型需要什么数据、基线和泛化测试，而不是把它当成通用 CFD 替代品。

## 学习单元

<details open>
<summary><strong>21｜计算图与微型自动微分</strong></summary>

计算图把表达式拆成节点与运算。反向传播从目标量出发，按链式法则把梯度传回各个输入。自动微分不是有限差分，也不是凭空“猜”导数；它根据程序中的运算规则传播导数。

**动手任务：** 用标量节点实现加法、乘法和反向传播，再用有限差分在若干输入点上检查梯度。有限差分只作为数值核对手段，需留意步长与舍入误差。

</details>

<details>
<summary><strong>22｜训练、优化与泛化</strong></summary>

训练集用于更新参数，验证集用于选择模型/超参数，测试集用于最终评估。若反复根据测试集结果调整模型，测试集就不再是独立的最终评估。

需要掌握损失函数、梯度下降、学习率、批次、正则化、早停、随机种子和基线模型。结果应报告多次运行或不确定性，而不是只挑一次最好的结果。

**工程提醒：** 数据归一化参数应只从训练集拟合；按时间、工况或几何划分数据时，应避免同一对象的近重复样本同时进入训练集和测试集。

</details>

<details>
<summary><strong>23｜卷积网络与空间特征</strong></summary>

卷积层通过局部连接和参数共享提取局部模式。输入张量的通道数、卷积核尺寸、步长、填充和输出尺寸都应明确。图像任务中学到的模式不一定直接适用于物理场：网格拓扑、坐标系、边界条件和守恒性质可能改变问题本身。

**练习：** 手算一个小型卷积层的输出尺寸，并说明把 CFD 网格场映射到规则网格可能引入什么误差。

</details>

<details>
<summary><strong>24｜PINN：用物理方程约束学习</strong></summary>

PINN 常把数据误差、控制方程残差和边界/初始条件误差组合成损失函数。例如一维稳态问题可将微分方程残差写成 \(r(x)=\mathcal{N}[u_\theta](x)-f(x)\)，再最小化采样点上的残差平方。

但“把物理方程写进损失函数”不等于自动满足物理规律。不同损失项尺度可能相差很大，梯度优化可能困难，采样点也可能覆盖不足。必须与解析解、传统数值解或可信基准进行比较。

**练习：** 先做一维热传导问题，分别报告内部残差、边界误差和整体解误差；不要只展示总 loss 曲线。

</details>

<details>
<summary><strong>25｜神经算子与代理模型</strong></summary>

神经算子尝试学习从输入函数到输出函数的映射，可用于参数化 PDE 解的快速近似。它的价值在于训练完成后对相近任务快速推断；代价则包括生成训练数据、训练成本、分布外误差和验证成本。

**CFD 场景必须问：** 训练数据覆盖哪些几何、雷诺数和边界条件？网格变化如何处理？守恒量和局部极值是否可靠？预测是否超出训练分布？与传统求解器相比，端到端成本是否真的更低？

**最终项目：** 建立简单解析/数值基线，按工况或几何划分数据，报告误差分布、失败案例、推理耗时和适用范围。明确说明代理模型不能替代的验证步骤。

</details>
