# 质量验收网关 (Quality Gates)

为了防止项目陷入“规划庞大、全盘烂尾”的困境，本项目为所有课程单元与工程实验定义了严格的**四级成熟度网关 (Quality Gates)**。每个单元均须明确标注文档当前的成熟度级别。

---

## 🚦 四级成熟度标准

```text
[G1: 索引级 (Index)] ➔ [G2: 实践级 (Practice)] ➔ [G3: 项目级 (Project)] ➔ [G4: 发布级 (Release)]
```

### Gate 1: 索引级 (Index Level)
- [ ] 原始资料权威真实，且具备第一手官方链接（非第三方营销二手文章）。
- [ ] 教材或规范的正文全文已确认可合法、完整阅读。
- [ ] 明确了该单元的先修知识要求、建议阅读范围与对应章节映射。
- [ ] 完成了版权与复用许可证审计（记录于 `docs/references/license-audit.md`）。

### Gate 2: 实践级 (Practice Level)
- [ ] 拥有作者自己梳理撰写的概念解析与机制阐述，绝非机械翻译或 AI 泛泛生成。
- [ ] 配套有最小可运行的实践代码或命令行验证步骤。
- [ ] 实验代码具备完整的输入、预期输出与运行依赖说明。
- [ ] 包含自检清单，学习者可自主验证是否真正理解。

### Gate 3: 项目级 (Project Level)
- [ ] 将零散概念整合成端到端可运行的工程小模块。
- [ ] 拥有严密的自动化测试套件，覆盖正常场景与边界异常退出场景。
- [ ] 明确记录了运行环境规格、已知限制（Limitations）与失效条件。
- [ ] 在 CI 流程中能够 100% 自动构建并验证通过。

### Gate 4: 发布级 (Release Level)
- [ ] 经过跨平台实机验证（如 Linux/WSL2/macOS）。
- [ ] 所有的超链接已通过自动化死链检测（Link Checker）。
- [ ] 文档文字遵循严谨中文技术排版规范与双许可协议要求。
- [ ] 接受社区外部学习者的复现反馈并消除模糊缺陷。

---

## 🚫 准入与发布阻断红线 (Blockers)

以下任何一项情况发生，该单元**严禁**标记为已完成或对外正式发布：
1. **来源不可见**：核心教材正文无法合法完整阅读，仅凭目录或短视频宣传揣测。
2. **代码未经执行**：仅贴出 AI 生成的代码，但从未在真实终端运行并捕获输出。
3. **以类比代替推导**：关键数学公式或硬件加速结论缺乏权威推导或性能测量支撑。
4. **版权侵权隐患**：将禁止改编（ND）的商业版权书籍直接全文洗稿搬运。
